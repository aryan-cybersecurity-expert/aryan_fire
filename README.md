# 🔥 Aryan Fire - Password Cracker

A fast, smart password recovery tool for **your own** protected files (PDF, ZIP, PPTX, DOCX).

> ⚠️ **DISCLAIMER:** Ye tool **SIRF EDUCATIONAL PURPOSE** ke liye hai. Apni hi file ka bhula hua password recover karne ke liye. Bina likhit permission kisi doosre ki file crack karna **IT Act 2000 (Sec 43 & 66)** ke under **CRIME** hai — 3 saal jail aur fine ho sakti hai.

## 🚀 Features
- **Smart Attack:** Filename se hi password ke guesses banata hai (super fast)
- **Dictionary Attack:** rockyou.txt jaise wordlists ke saath
- **Multithreading:** 4-8 threads se parallel checking
- **Supported Formats:** PDF, ZIP, PPTX, DOCX, XLSX
- **Beautiful Terminal UI:** Green ASCII banner + disclaimer
